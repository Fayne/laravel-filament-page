# 页面结构模板

页面编辑页的“保存为模板”保存已保存的页面架构；有未保存修改时要求先保存。它取代页面级组件内容导入/导出，组件库定义导入/导出保留。

模板保留页面类型、普通/固定组件、嵌套 Widget 类型、数量、顺序和内部标题。普通字段值、媒体、实体引用、HTTP 配置、敏感值及未知属性均不进入模板。新建页面通过“从模板创建”选择启用模板；应用会替换当前尚未保存的结构，每层生成新的 key，表单其余页面设置保留，模板与页面互不联动。字段定义自己的默认值仍按正常表单行为生效。

模板管理支持查看结构、名称/说明修改、启停和删除，不提供原始结构 JSON 编辑。模板使用租户隔离和区域数据库，权限暂复用 PageComponent 管理权限；保存模板还要求查看来源页面，应用模板要求模板查看和页面创建权限。

当前定义缺失、固定布局变更或页面类型不可用时拒绝应用。创建页面时仍执行正常字段校验、路径唯一性及页面类型数量限制。

已验证结构清理、父子 key 独立生成、数据库读写、租户隔离、资源自动加载、后台路由与 Blade 编译。浏览器保存模板、模板弹窗应用、页面保存重开尚待验收。
